## Weather subpage (`/pogoda`) — Carbon Health design system

New dashboard page: field's weather forecast. **48h hourly** (temp + rain probability, scrollable hour tiles) and **7-day daily** rows. Field selectable via SelectInput (default = first field), weather queried by the field's real centroid through the existing provider seam. Polish UI, follows DESIGN.md throughout.

### Design adherence
- White canvas, Carbon Teal accent only on selected/active states, paired clinical status colors (never large fills)
- JetBrains Mono + tabular figures for all numeric data (temps, precip%, wind, mm)
- 8px spacing grid, Card component (`rounded-xl` + `shadow-card`), 2px teal focus ring (inherited)
- Skeleton loaders (not spinners), `active:scale-[0.98]` tactile feedback on interactive tiles, reduced-motion respected
- WMO codes mapped to status-aware color (rain → info/sky, storm → urgent/red) paired with a Phosphor icon + text label (color-independent per a11y)
- No em-dashes in UI text

### Data layer (provider seam)
1. `lib/types.ts` — append `WeatherHour`, `WeatherDayForecast`, `WeatherCode`, `FieldForecast`
2. `lib/providers/types.ts` — add `getHourlyForecast(fieldId)` + `getDailyForecast(fieldId)` to `IWeatherProvider`
3. `lib/providers/open-meteo.ts` — live impl (one request, `forecast_days=7`, `timezone=auto` so hours are local; hourly vars incl. `precipitation_probability`, `precipitation`, `weather_code`; daily vars incl. `*_max/min`, `precipitation_sum`, `wind_speed_10m_max`; slice hourly to 48)
4. `lib/mock/data.ts` + `lib/providers/mock-weather.ts` — deterministic mock generators (48h + 7d), serves the `OPEN_METEO_BASE_URL=mock` opt-out
5. `app/api/fields/[id]/forecast/route.ts` (new, server-only) — folds `{ hourly, daily }`, `Cache-Control: s-maxage=600, swr=1800`

### UI
6. `lib/weather-codes.ts` (new) — WMO code → `{ label: "Przejaśnienia", status }` Polish map
7. `components/weather/WeatherIcon.tsx` (client) — WMO code → Phosphor icon via existing `<Icon>` wrapper (`Cloud`, `CloudSun`, `CloudRain`, `CloudSnow`, `CloudFog`, `CloudLightning`, `Sun`)
8. `components/weather/HourlyForecastCard.tsx` — horizontal scroll strip of 48 tiles: hour label (local), mono temp, `Drop` icon + precip% with mini bar; current hour highlighted
9. `components/weather/DailyForecastCard.tsx` — 7 rows: weekday + date, `WeatherIcon`, min–max temp track, precip% + mm, wind
10. `components/weather/WeatherView.tsx` (client) — field `SelectInput` via `useFieldsStore` (hydrated+seed pattern, default `fields[0]`); resolved centroid subtitle; fetches the BFF; renders the two cards with matching skeletons
11. `app/(dashboard)/weather/page.tsx` (new) + `lib/navigation.ts` entry (`CloudSun` icon, "Pogoda")

### Out of scope
No store persistence (weather is ephemeral), no map/historical-weather changes. Light `AGENTS.md` File Map update.
