## Goal
Merge `/soil-sensor` (soil reading cards) + `/sensor-settings` (all-devices status table) into a single new **`/sensors`** route. Main view = a **card grid of ALL sensors** (every kind): soil probes show their metric cards, others show status/battery/last-seen. Each card has edit + an expandable per-card "Szczegóły techniczne" debug toggle. Add/edit via a modal mirroring the field editor.

## New files
1. **`lib/sensors-store.ts`** — Zustand persisted store mirroring `lib/fields-store.ts` (`skipHydration` + manual `rehydrate()`), seeded from `sensors` in mock data, persisted to localStorage key `cowpolupiszczy-sensors`. API: `sensors`, `hydrated`, `addSensor`/`updateSensor`/`deleteSensor`/`rehydrate`, plus `useSensors()`/`useSensorsHydrated()` selectors.
2. **`components/sensors/SensorEditorModal.tsx`** — add/edit modal mirroring `FieldEditorModal` (`Modal size="lg"`, form remounts via `key`). Fields via existing `TextInput`/`SelectInput`/`optionsFromRecord`: name, kind, field, status, battery, last-seen, lng/lat. Footer: Delete (edit-only, two-click confirm), Anuluj, Zapisz/Dodaj.
3. **`components/sensors/SensorCard.tsx`** — one card for any kind. Soil shows the moisture/temp/EC metric grid (reusing `SoilMetric` visual + `sensorProvider.getReadings`, skeleton-first, "Brak odczytów." fallback); others show battery + last-seen. Footer: Edit + "Szczegóły techniczne" toggle (CaretDown/Up) revealing a raw `<dl>` (id, kind enum, fieldId, GPS coords, status, battery, lastSeen) and, for soil, the recent readings series.
4. **`components/sensors/SensorsView.tsx`** — client page body. Rehydrates store, renders seed list until hydrated (avoids SSR mismatch), header + "Nowy czujnik" button, `md:grid-cols-2` of `SensorCard`, owns the editor open state.
5. **`app/(dashboard)/sensors/page.tsx`** — server wrapper (header container + `<SensorsView />`).
